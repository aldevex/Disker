Codebase explanation (src/):

Memory (mem/):
"darray.h": Dynamic array code.
"darray_imp.c": Dynamic array core implementation.
"string.h": Dynamic string and string view code (DO NOT ATTEMPT TO READ THIS).
"mem.h": Includes the aforementioned code + some helper macros.

Entry (entry/):
"app.c": Entry for TUI.

Core (core/):
"main_tui.h": TUI instruction parsing code. Contains core main function "tuiMain".
"instructions.h": Disker instruction structures.
"state.h": Program instructions state. Included by "main_tui.h".
"ssimp_linux.c": Linux implementation of system-specific functions.
"ssimp_win.c": Windows implementation of system-specific functions.

Utility (utils/):
"generic.h": Generic utility code.
    Non-system-specific functions are inline for inclusion in multiple .c files.

Disk or disk image file geometry (geo/):
"geo.hpp": Includes file format enum & geometry variant structure.
"raw.hpp": Code for raw disk images and real disks.

Disk scheme & structures (scheme/):
"scheme.hpp": Includes scheme enum & total scheme data structure.
"mbr.hpp": MBR scheme structures.
"gpt.hpp": GPT scheme structures.

File systems (fs/):
"fs.hpp": Includes file system enum & file system variant structure.
"fat32.hpp": FAT32 structures.

Total disk info collection (diskinfo.h):
- Collection of all disk or disk image information
- Disk and disk image read/write code
